# Meraki Roots OceanWP Child Theme

Version: 1.2.0
Parent theme: OceanWP

This child theme provides the Meraki Roots brand shell, WooCommerce product display enhancements, product-detail accordions, COA callouts, lab-results shortcode, clean header/footer, and page templates.

## Required parent/plugins

- OceanWP parent theme
- WooCommerce
- Ocean Extra recommended
- Yoast SEO free supported through product import meta
- Redirection recommended for Shopify URL redirects
- LiteSpeed Cache recommended for Hostinger

## Important

Do not add empty WooCommerce template overrides. This theme intentionally uses WooCommerce hooks first.
